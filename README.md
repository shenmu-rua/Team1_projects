# Team1_projects

这是用于存放当前及后续多个项目的父目录。每个项目使用独立子文件夹，
项目说明、代码、配置、规范、数据和生成文件均放在对应项目内部。

目录组织示意：

```text
Team1_projects/
├── README.md                # 父目录说明
├── AGENTS.md                # 多项目共用的目录约定
├── .gitignore               # 通用缓存、环境和编辑器文件规则
├── <项目目录>/
│   ├── README.md            # 项目说明与运行方式
│   ├── AGENTS.md            # 项目专属规范
│   ├── .gitignore           # 项目专属忽略规则
│   └── ...                 # 项目的代码、文档、配置及本地文件
└── <后续项目目录>/
    └── ...
```

开始某个项目时，先进入对应子目录，阅读其中的 README 和 AGENTS，再运行该项目的命令。
父目录不记录具体项目的业务内容、阶段进展、数据访问口径或安装步骤。
