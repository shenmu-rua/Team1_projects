# 数据字典（仅表结构）

本字典在初始化阶段仅通过只读 SQLite 结构元信息生成，不含业务数据行、样本、计数或聚合。
只列普通表；视图、虚拟表及 SQLite 内部表不在本次范围。
声明类型和 NOT NULL 是建表约束，不代表实际值类型或缺失情况。
字段语义、记录粒度、关联关系、时间口径和清洗规则均待确认。
主键序号 0 表示未声明主键；隐藏标记 0=普通列，2/3=生成列。
默认值及其表达式不输出。
