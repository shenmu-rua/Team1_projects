## 参考规范适配

| 参考内容 | 本项目处理 | 理由 |
| --- | --- | --- |
| `signal_insight` 包名和西塔业务 | 本项目命名为 `genshin_insight`；旧文档保留作参考 | 原文是另一业务的模板 |
| 原规范允许聚合结果 | 本次连聚合值也不读取 | 当前用户要求仅表头结构，范围更严格 |
| `ods_/dwd_/dim_/dws_/ads_` | 作为后续产物分层；不重命名已有库表 | 保留原始库；不先假设已有表的清洗状态 |
| 四套主题、自动注册与 TOML 切换 | 当前只接入实际存在的蓝粉主题 | 原文 API 不等于本仓库已实现功能 |
| 参考标题 16 pt；蓝粉基准 22 pt | 使用 skill 的 16 英寸基准 22 pt，随宽度缩放，刻度至少 8 pt | 按指定主题保持版式比例；在此登记字号偏离 |
| 标题主色短条 | 项目 `viz.finish` 默认启用 | 引擎默认关闭；项目规范要求该部件 |
| `patch.linewidth` | 适配器应用主题后设置为 1.0 | 扩展指南明确要求避免设为 0 导致箭头消失 |
| 连续数值色阶 | 提供 `viz.sequential_cmap()`，主粉单色由浅到深 | 图表规范要求单色渐变；不直接使用引擎的蓝粉跨色阶 |
| PPT 16:9 | 显式 `canvas("ppt", width_in=16, height_in=9)` | 引擎 `slide` 预设为 16:9.4，不能直接当作 PPT |
| 原文 78 项测试、真实库 smoke | 当前独立测试，仅临时空表；不提供真实数据 smoke | 旧测试数量和读取范围不适用于本阶段 |

## 当前验证方式

在子项目根目录运行：

```powershell
python -m pytest
python -m ruff check src test
python -m ruff format --check src test
```

当前包含 17 项测试：结构字段、复合主键、生成列、引号标识符、内部对象跳过、
不存在的库不创建、查询/聚合/写入/附库等操作拒绝、帮助命令不连接库、import 无副作用。
所有测试只创建临时空表，不写入任何业务记录，不连接真实库。

若受限环境无法创建系统临时目录，可用一个不存在的项目内临时目录：

```powershell
python -m pytest --basetemp=.pytest_cache/unique-run-directory
```

`--basetemp` 必须指向专用测试目录；pytest 会清理该目录，不能指向数据目录或项目根目录。
当前机器的 Python、pytest、pandas、NumPy、Matplotlib 等依赖已存在，无需为本次验证联网安装。

本次验证结果：17 项测试通过，Ruff 检查及格式检查通过；wheel 构建成功，
包内包含项目代码、蓝粉主题代码和包元信息，不含数据文件；从 wheel 加载的帮助命令通过。
