# 可交互数据大屏

大屏版本1.0.0，制作于2026-10-25。源码依工程规范第2、3、12条放在既有包和viz目录，
交付放在reports的dashboard目录（使用项目专属忽略规则），验证放在test/unit；父目录不增加业务文件。

## 制作与展示

在项目根目录执行，使用本机已有Python环境及presentation/viz依赖：

```powershell
$env:PYTHONPATH = 'src;.'
python -m genshin_insight dashboard --serve
```

默认读取 `image/analysis_20261019_final/ads.json`。不连接数据库，不重新清洗或聚合明细，
不读取其他来源数据集对比章节。构建器按字段允许清单提取页面需要的聚合，
检查数据集、稽核状态、发布门槛、抑制值、卡池总量与账号分箱对账，拒绝疑似标识名称。

输出 `reports/dashboard_<时间>/index.html`、构建清单、使用说明及字体许可附件。
HTML包含页面所需全部聚合、样式、脚本和Noto Sans SC字体子集，单独复制HTML即可离线运行。
不请求CDN、外部接口或追踪服务。构建清单记录ADS、源码和HTML的SHA-256。

当前演示交付目录为 `reports/dashboard_20261025_demo/`。需要重建此目录时显式运行：

```powershell
python -m genshin_insight dashboard --output reports/dashboard_20261025_demo --replace
```

默认不覆盖已有目录。`--replace`只接受带大屏构建清单的目录，不删除目录中的其他文件。
单独启动已有页面：

```powershell
python -m genshin_insight dashboard --existing reports/dashboard_20261025_demo --port 8766
```

服务只绑定127.0.0.1，根目录仅为本次交付目录；不开放项目源码、原库或清洗库。
不启动服务时也可直接双击index.html。16:9桌面画布随浏览器窗口等比适配；窄屏按图表纵向排列。

## 联动范围与统计口径

| 操作或模块 | 范围及限制 |
| --- | --- |
| 卡池选择 | 联动关键指标、月度趋势、五星观察；301/400合并为角色活动池 |
| 月份起止与快捷范围 | 仅筛选月度趋势；起止倒置时自动收拢为同一个月份 |
| 月度折线 | 四池共用单一零起点纵轴；缺失或抑制格断线，不补零、不插值 |
| 星期小时矩阵 | 全局7×24累计抽数，格内单位万抽，悬停为精确数值；不推算活跃 |
| 账号记录量 | 全局来源内去重账号；安全合箱用横条表示账号数，不把变宽分箱伪装为等宽直方图 |
| 相邻五星间隔 | 各池独立分箱；全池视图默认角色池；新手池无发布间隔时明确空状态 |
| 账号分组占比 | 各池按账号抽数分组；点为中位数，区间为P25–P75，不是置信区间；边界重复会合组 |
| 名称榜 | 仅已有前12个精确原始名称；搜索、升降序排列，不合并多语言别名；覆盖率分母为全部五星记录 |

关键指标的账号数在相应来源或卡池内去重，不累加卡池账号数。记录内五星占比不是官方概率。
月份、名称和间隔分箱贡献人数是保守下界，不在筛选后重新推算账号数或隐藏格。
时间为历史归档2020-12—2022-07，时区未知；页头时钟明确为展示时间，不表示数据实时更新。

## 视觉与交互

沿用theme/theme.py的蓝粉颜色和viz/plots.py的卡池固定映射；页面用原生SVG与DOM图表，
不依赖Plotly。网页图表用标题、口径、单轴、零基线、来源页脚和详情说明实现与静态图相同的阅读要求，
不通过Matplotlib的finish/save导出。字体随HTML内嵌；连续热力采用单粉色阶，避免彩虹色阶、双轴与环形图。

图表悬停或聚焦显示数值。月度点可点击固定该月解读；各图右上角可打开大图与聚合表。
名称搜索只在已发布的前12项内匹配，空结果有明确提示。
点击“自动轮播”后每8秒切换卡池；手动筛选或查看详情会暂停，页面隐藏时暂停计时。
遵循减少动画的系统偏好；支持键盘与对话框焦点返回。

快捷键：F全屏、P轮播、R复位、/聚焦名称搜索、Esc关闭详情。
页面不自动请求全屏；全屏只响应用户按钮或快捷键。
