## 怎么用这张表

- 每个任务都有 ID，指派时直接写「`D3-02` 归 A」即可
- 「前置」为空表示可以立刻开工
- 「判定」是**可验证**的完成标准，不是"觉得差不多了"
- 预计工时按"熟悉本项目的人"估，新人乘 1.5–2

## 交接最小集（把某块给别人时，这六样缺一不可）

1. **输入**：原始库路径或 ADS 路径 + 校验值
2. **命令**：能直接粘贴的执行命令（含全部参数）
3. **模板/素材**：Word 模板 docx、背景视频这类不在仓库里的文件（原样传，别另存）
4. **验收**：这条线的判定标准（本文档对应行的「判定」列）
5. **已知坑**：模板哈希、字体缓存、Word 域刷新、白场秒数
6. **联系人**：这条线原来谁负责、什么情况下该问他
