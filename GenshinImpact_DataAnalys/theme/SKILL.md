# 蓝粉 · 图表主题

冷场暖图。蓝铺地面和结构，粉出数据和重点，雾紫卡在两者中间做过渡 ——
蓝（215°）和粉（340°）在色轮上隔得远，直接并置会「跳」，中间那层紫是关键。

## 什么时候用

- 需要**冷色调**图表，且不想出现边框
- 有「过去 vs 现在」「基线 vs 现状」的对比
- 报告、PPT、展示平台里要一整套观感统一的图

## 硬约束（来自项目《图表规范》的禁止项，不得违反）

| 禁止项 | 本主题的处理 |
| --- | --- |
| 双 Y 轴 | 引擎不提供 `twinx` / `twiny`；`lint_figure` 直接报错 |
| 3D 图 | 不提供 |
| 饼图 / 环形图 | 不提供。构成改用横向条形 + 百分比标注 |
| 纵轴截断的柱状图 | 柱状图基线必须在 0，`lint_figure` 拦截 |
| 图例超过 7 项 | `finish(legend=...)` 超过 7 项直接抛异常 |
| 刻度小于 8 磅 | `lint_figure` 拦截 |
| 个人标识 | `lint_figure` 扫描图上的手机号、IMSI、任何 11 位以上连续数字 |
| 彩虹色阶 | 只有主题内的单色 / 双色渐变（`seq_cmap`、`ramp`） |
| 商业字体名 | 回退链里一个都不写，`lint_figure` 也会拦 |

默认版式：

- **淡框**：坐标区带一圈闭合框，用与坐标轴同档的淡色 `AXIS = #C3D0E0`、1.0 pt。
  地面只比页边深一丁点，去掉框之后整块版面会糊在一起、左侧标签栏也失去附着点 ——
  淡框是「有结构」和「不压数据」之间的折中。
  换法：`axes(fig, top=…, frame="none")` 完全去框，`frame="ink"` 换成墨黑框。
- **不打刻度线**：刻度值直接标在轴上。

自检分两级：上面这些是**禁止项**，触犯即抛；标题超 40 字、缺来源行只算**建议**，不拦截。

## 版式约定

字号以原主题画布 **16 in 宽** 为基准（标题 22 pt、副标题 12 pt、刻度 11.5 pt…），
画布变宽变窄时 `apply_theme(width_in=…)` 按比例缩放，任何尺寸下版面比例一致。
**200 dpi**。

| 部件 | 规格 |
| --- | --- |
| 标题 | 22 pt 加粗，写结论含关键数字，≤ 40 字，数字用 f-string 算 |
| 副标题 / 限制 | 12 pt，写口径：对象、时间、统计方法、限制 |
| 图例 | 12 pt |
| 坐标轴 / 刻度 | 11.5 pt，轴用 `AXIS` 淡色、0.8 pt，不打刻度线 |
| 图内数值标签 | 12.5 pt |
| 来源行 | 9.5 pt，左下角，`FAINT` 色 |
| 版心 | 左 0.075 / 右 0.925 —— 标题、坐标区、来源行共用这两条竖线 |

**类目名写在坐标区里面**（`label_column()`），不挂到画面左侧外面。
这样坐标区左边界能一直留在版心 0.075 上，和标题对齐，长类目名也不会被左边缘切掉。

## 用法

```python
import sys; sys.path.insert(0, "<skill-directory>")
import theme as T, spec_check

T.apply_theme(width_in=10)            # 打印本机生效的字体

fig = T.canvas("slide")               # "slide" 与原主题同比例 / "ppt" 严格 16:9
                                      # "report" 宽 15.4 cm

# 先 finish 拿到标题块底部，再建坐标区 —— 两者不会打架
top = T.finish(fig,
               title=f"西塔 {peak_h} 点达到峰值 {peak:,} 人，比太原街晚 2 小时",
               subtitle="10-03 每人每小时一个位置；区域可重叠，分别计数、不能相加",
               source=T.source_line("沈阳移动信令样本（脱敏，2018 国庆）",
                                    "D14_展示平台", "2.0.0+3f2a9c1d"),
               legend=[{"kind": "line", "label": "西塔", "color": T.PINK_500},
                       {"kind": "line", "label": "太原街", "color": T.BLUE_500}],
               filename="D14_03_联动矩阵.png")

ax = T.axes(fig, top=top, grid="y")   # 只画淡化的坐标轴，无框

# …在这里画数据，全部用主题色常量…

spec_check.lint_figure(fig)           # 禁止项自检，触犯即抛
T.save(fig)
```

类目名放框内：

```python
ax.set_xlim(-52, 620)                 # 左边留出标签栏宽度
ax.set_yticks([])
T.label_column(ax, [(4, "南巷奶咖"), (3, "果C工坊")], x_sep=0, x_text=-6)
```

**水印**：模拟分区出的图必须打 —— `T.watermark(fig)`。

## 取色

| 用途 | 常量 |
| --- | --- |
| 主色（要读者看的那个） | `T.MAIN` `T.PINK_500` |
| 主色浅 / 中 | `T.MAIN_LIGHT` `T.MAIN_MID` |
| 过去 / 基线 / 对比项 | `T.PAST` `T.BLUE_500` |
| 双色同现时的第三色 | `T.BRIDGE` `T.VIOLET_400` |
| 背景对象（不强调的类别） | `T.GRAY` |
| 警示 / 警告 / 通过 | `T.RED` `T.AMBER` `T.GREEN` |
| 正文 / 次要 / 来源行 | `T.INK` `T.MUTED` `T.FAINT` |
| 多系列顺序 | `T.SERIES` |

原则：**灰色打底，一种颜色强调一件事，红只用于警示。**

## 图元

| 函数 | 用来画 |
| --- | --- |
| `T.dumbbell(ax, y, before, after)` | 前后对比：连接带做「蓝→粉」渐变，蓝空心点是过去，粉实心点是现在 |
| `T.hbar(ax, y, x0, x1, h, color)` | 直角横条（比大小、构成） |
| `T.gradient_hbar(...)` | 横向渐变条 |
| `T.gradient_fill_between(...)` | 线下渐变面积（折线图） |
| `T.value_label(ax, x, y, text, color)` | 数值标签，紧跟图元 |
| `T.seq_cmap()` | 连续色板：低=冷，高=暖，途经雾紫 |
| `T.ramp(n, c0, c1)` | 两端色之间等距取 n 个色 |
| `T.bar_baseline_zero(ax, values)` | 柱状图基线锁 0 |
| `T.label_column(ax, rows, x_sep, x_text)` | 框内左侧标签栏：类目名写进坐标区，配一条 y 轴淡线 |
| `T.watermark(fig)` | 模拟数据水印 |

## 选图对照（规范第 4 节）

| 要回答的问题 | 用 | 不用 |
| --- | --- | --- |
| 随时间怎么变 | 折线 | 柱状图堆满 24 根 |
| 几类之间比大小 | 横向条形，按大小排序 | 饼图 |
| 构成占比 | 条形 + 百分比标注 | 饼图、**环形图** |
| 分布 | 直方图、ECDF | 只给平均数 |
| 两个指标的关系 | 散点 | 双轴折线 |
| 矩阵 | 热力矩阵，格子里写数字 | 和弦图 |
| 前后对比 | 哑铃图、斜率图 | 两张独立的图 |

## 字体

用项目原有的一套：**Noto Sans SC**，配套四个静态字重（Light 300 / Regular 400 /
Medium 500 / Bold 700）由 `prepare_fonts.py` 从系统可变字体拆出，放在
`图表主题_粉黛净蓝/theme/fonts/`。

`theme.py` 按顺序找字体，找到即用：

```
<skill目录>/fonts/  →  ~/.dsh/skills/_fonts/
```

两个目录都没有时，回落到系统已安装的字体（Noto Sans SC / 思源黑体）。

回退链只写开源字体名：`Noto Sans SC → Source Han Sans SC → Noto Sans CJK SC
→ Noto Sans CJK JP → DejaVu Sans`。**不含任何商业字体名** —— 微软雅黑、黑体这类
在规范第 0 节是合规红线，学生作品进简历或作品集时尤其要紧。

> **分享给别人时**，skill 目录里没有字体文件，两种做法：
> 1. 让对方装 **思源黑体 / Noto Sans SC**（规范本来就要求装），代码不用改；
> 2. 把四个字重（Light / Regular / Medium / Bold）拷进 `<skill目录>/fonts/`，
>    对方不装字体也能出图。两个 skill 可以共用一份，放 `~/.dsh/skills/_fonts/`。
