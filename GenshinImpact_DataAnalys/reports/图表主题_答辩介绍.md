# 两套图表主题 · 答辩介绍

> 答辩被问到"你做的图表主题是什么"时用这份。两个主题：**蓝粉**（冷调）和**黄红**（暖调），版式规范完全一致，只有配色不同。每节都有可直接朗读的口播稿，后面是依据与预设问答。

---

## 一、开场：我做了两套主题，共用一副骨架

各位老师好，我做的图表主题有两套：**蓝粉**和**黄红**。

它们不是"两套不同的图表规范"，而是**同一套规范的两种配色**。版式、字号、间距、禁止项、自检代码全部共用，差别只在色板。所以同一份绘图代码，只要换一行 import，就能出冷调或暖调的整组图，混着用也不会打架。

一句话概括两套的气质：**蓝粉是冷蓝地面配藕粉数据，雾紫做过渡；黄红是米黄纸配朱红字，石青作冷色第三笔。**

---

## 二、共同骨架：为什么能"只换配色"

### 2.1 一套 API

两个 `theme.py` 结构一模一样，对外暴露同一组名字：

| 语义 | 含义 | 蓝粉取值 | 黄红取值 |
| --- | --- | --- | --- |
| `MAIN` | 要读者看的那个 | 藕粉 `#C9668B` | 朱红 `#C74B38` |
| `PAST` | 过去 / 基线 / 对比 | 烟蓝 `#5A7BAC` | 石青 `#3F7078` |
| `NOW` | 现在 / 现状 | 藕粉同档 | 朱红同档 |
| `BRIDGE` | 冷暖同时出现时的过渡 | 雾紫 `#9E92CC` | 赭黄 `#B8873A` |
| `ALERT` | 下降 / 不通过 | `#B2574A` | `#9E3355` 绛紫 |
| `GRAY` | 背景对象、不强调的类别 | `#C4CAD3` | `#C9C2B4` |
| `INK` / `INK_SOFT` / `MUTED` / `FAINT` | 四级文字，由重到轻 | `#1A2233` → `#8B97AE` | `#2B2A26` → `#9A9284` |

绘图代码只写 `T.MAIN`、`T.PAST`，不写死色值。所以哪天要换调性，改的是 import，不是几十个十六进制码。

### 2.2 一套版式

字号以 **16 英寸画布宽**为基准，画布变宽变窄时按比例缩放，任何尺寸下版面比例不变：

| 部件 | 规格 |
| --- | --- |
| 标题 | 22 pt 加粗，写结论、含关键数字，≤ 40 字 |
| 副标题 | 12 pt，写口径：对象、时间、统计方法、限制 |
| 图例 | 12 pt |
| 坐标轴 / 刻度 | 11.5 pt，轴用淡色 0.8 pt，**不打刻度线** |
| 图内数值标签 | 12.5 pt |
| 来源行 | 9.5 pt，左下角，最淡那档 |
| 版心 | 左 0.075 / 右 0.925——标题、坐标区、来源行共用这两条竖线 |
| 输出 | 200 dpi |

两个细节值得单独说：

- **类目名写在坐标区里面**，不挂到画面左侧外面。这样坐标区左边界能一直压在版心 0.075 上，和标题左对齐，长类目名也不会被边缘切掉。
- **默认带一圈淡框**（与坐标轴同档的淡色、1 pt），需要时 `frame="none"` 去框、`frame="ink"` 换墨黑框。

### 2.3 一套硬约束

两套主题共用同一份 `spec_check.py`，检查《图表规范》的**禁止项**，触犯即抛 `SpecViolation`：

1. 双 Y 轴
2. 3D 图
3. 饼图 / 环形图
4. 柱状图纵轴截断（基线不在 0）
5. 图例超过 7 项
6. 刻度小于 8 磅
7. 商业字体名
8. 图上出现手机号、IMSI 或任何 11 位以上连续数字

另外"彩虹色阶"在引擎层面就不提供——只给单色渐变和双色渐变，从源头上避免色相当数值刻度。

自检分两级：上面这些是**禁止项，触犯即抛**；标题超 40 字、缺来源行只是**建议**，只提醒不拦截——因为那属于判断问题，不该由代码替人做决定。

而且这道闸门挂在保存入口上：`save()` 落盘前先 `lint_figure(fig, strict=True)`，**不合规的图存不下来**；还有单元测试专门断言违规必须抛异常，防止有人把它注释掉。

## 三、蓝粉：冷调

### 3.1 配色逻辑：蓝和粉隔得远，中间必须有座桥

蓝和粉在色轮上离得很开，直接放在一起会打架。所以中间那层**雾紫**不是装饰，是必需品——它负责让冷场和暖图能共处一张图而不割裂。

**冷蓝做"场"（地面、结构、过去），藕粉做"图"（现在、重点、增长），雾紫卡在两者之间做过渡。**

| 层 | 色值 |
| --- | --- |
| 冷轴 · 烟蓝 | `#5A7BAC` 主蓝、`#30496C` 深蓝、`#A6C0DE` 浅蓝 |
| 暖轴 · 藕粉 | `#C9668B` 主粉、`#803A55` 深粉、`#EBABC2` 浅粉 |
| 桥 · 雾紫 | `#9E92CC` |
| 画布 | `#F6F8FC` 页边、`#EEF4FB` 地面、`#DCE7F4` 网格、`#C3D0E0` 轴线 |
| 文字 | `#1A2233` / `#3B4761` / `#68758F` / `#8B97AE` 四级 |

画布全部偏冷偏淡，主动退到后面；文字用蓝紫调灰阶而不是纯黑，避免和藕粉抢注意力。

### 3.2 实际用法：卡池颜色锁死

在正式项目里，这套主题最重要的约定是**颜色即语义**：新手祈愿雾紫、常驻祈愿烟蓝、角色活动祈愿藕粉、武器活动祈愿深蓝。

七张图会反复出现同一批卡池。如果每张图各挑一次颜色，读者就得在每张图里重新建立"粉是哪个池"的映射，跨图比较立刻失效。锁死之后，读者在第一张图里学会一次，后面全部通用。

## 四、黄红：暖调

### 4.1 配色逻辑：暖底吃暖色，必须有一块冷色来撬

这套的难点和蓝粉正好相反。黄和红都在暖端，而米黄的地面也是暖的——**暖底吃暖色，朱红会"沉"进背景里**，读者抓不住重点。

所以这套主题必须有一个冷色来撬开，就是**石青**。它既是整套配色里唯一能把朱红顶起来的力量，又兼任"过去 / 对比"那一轴。而「黄」出现在两处：米黄的**地面**，以及第三系列与强调层级用的**赭黄**——名字里的两个字，一个当地，一个当强调。

| 层 | 色值 |
| --- | --- |
| 冷轴 · 石青 | `#3F7078` 主青、`#224045` 深青、`#8FB4BA` 浅青 |
| 暖轴 · 朱红 | `#C74B38` 主红、`#82281D` 深红、`#EC9C8E` 浅红 |
| 桥 · 赭黄 | `#B8873A`、浅档 `#D9B678` |
| 画布 | `#F5F1E6` 米黄页边、`#FCFAF3` 地面、`#E7E1D2` 网格、`#CFC7B4` 轴线、`#FFFDF8` 暖白 |
| 文字 | `#2B2A26` / `#4A453C` / `#6E675A` / `#9A9284` 四级 |

### 4.2 三个可以讲深的细节

**① 警示色不能再用红。** 红已经是主色了，如果"下降"也用红，"重点"和"出问题"就分不开。所以警示另起一色：绛紫 `#9E3355`；警告用琥珀 `#C8861A`，通过用橄榄绿 `#6B8E4E`。

**② 连接带只取青→红两端直接插值，中间不绕色相。** 青在 190°、红在 5°，若绕经赭黄实际要跨过绿和黄，连接带会变成一条小彩虹。连接带本身是一条信息，不该是色相旅程。两端直插的中间色落在 `#835E58`（暖灰褐），在米黄地面上收得住。

**③ 什么时候用这套。** 需要暖色调、整体是米色/纸质/国风调性时用；冷色主题放在这类版面上会打架。特别适合"过去 vs 现在""基线 vs 现状"这种对比表达——哑铃图加渐变连接带就是为它准备的。

## 五、两套并列看

| 维度 | 蓝粉 | 黄红 |
| --- | --- | --- |
| 一句话 | 冷蓝地、藕粉图、雾紫桥 | 米黄纸、朱红字、石青第三笔 |
| 场（地面） | 雾蓝 `#EEF4FB` | 浅米黄 `#FCFAF3` |
| 图（重点） | 藕粉 `#C9668B` | 朱红 `#C74B38` |
| 冷色轴 | 烟蓝（本身是场） | 石青（撬开暖底的杠杆） |
| 桥色 | 雾紫 | 赭黄 |
| 警示 | `#B2574A` | `#9E3355` 绛紫 |
| 适用 | 冷调报告、PPT | 暖调、纸质、国风调性 |
| 版式 / 字号 / 禁止项 | 完全相同 | 完全相同 |

**结论：两套不是二选一的技术路线，而是同一套方法的两种语气。**

## 六、本项目用的是哪套

这个项目用的是**蓝粉**（`config.THEME_NAME = "bluepink"`）。原因是图集同时用于投影 PPT 和 A4 打印报告，冷白底在投影上更稳、在打印上也干净；暖调更适合纸质读物，而这份报告有相当篇幅是投影讲解。

黄红不是备而不用——它是同一套引擎的另一套色板，任何时候把 `theme` 换成黄红版，绘图代码一行都不用改。

## 七、可能被追问的问题

**Q：两套主题会不会"混着用就乱"？**
不会，因为版式和字号完全一致，只有色板不同。混用的风险不在视觉，而在语义——所以第二轮约定是：同一份交付物只用一套，不要一张图冷一张图暖。

**Q：为什么不做成一个主题加一个配色开关？**
现在其实就是这个结构：两个 `theme.py` 的 API 完全对齐，可以理解成同一引擎的两份调色板。做成一个文件也行，但分开放更便于随包分享（`蓝粉/`、`黄红/` 各自带字体和说明书，拿到就能跑）。

**Q：黄红为什么不用红色做警示？**
红在这套里已经是主色。重点和"出问题"共用一个色相，读者会误判情绪强度。所以警示另起绛紫，警告用琥珀——三个层级三支色，互不侵占。

**Q：为什么严禁双 Y 轴？**
两条量纲不同的曲线放同一坐标区，视觉交点没有统计含义，容易被读成因果。需要对比就分面，或统一到同一分母再画。

**Q：柱状图为什么必须零基线？**
截断纵轴会让 5% 的差异看起来像 50%。零基线让柱子长度比例等于数值比例，这是柱形唯一的优势。

**Q：自检会不会误伤正常图？**
禁止项都是形式问题（双轴、饼图、字号、图例数量），不存在"合理例外"。而真正需要判断的（标题是否超 40 字、有没有写来源）只做建议、不拦截——这条边界是刻意划的。

**Q：200 dpi、16 英寸、版心 0.075/0.925 这些数字哪来的？**
分别对应打印分辨率、投影比例和版式栅格。图要同时用于投影和打印，尺寸必须在两个媒界上都成立。

**Q：换主题要改多少代码？**
一行 import。取色全靠语义常量，版式靠 `finish/axes` 这类函数，所以绘图逻辑里没有硬编码色值和坐标。

**Q：两套主题里哪个是你更想推的？**
不是"更想推"，而是按交付物选：投影为主选蓝粉，纸质/国风为主选黄红。同一个项目也可以分阶段用不同主题，只要在同一份交付物里保持一致。
