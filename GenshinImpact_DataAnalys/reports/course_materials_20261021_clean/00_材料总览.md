本材料包包含两份报告、两份自建模板、分析代码、数据与协作说明、离线展示系统和复现依据。报告中的统计数字来自受保护聚合，不包含原始库、明细行、UID 或抽卡 ID。

## 材料构成

| 目录 | 内容 |
| --- | --- |
| 01_自建报告模板 | 数据分析报告与数据质量分析报告的蓝粉主题 Word 模板，以及模板设计说明 |
| 02_报告 | 两份正式报告的 docx 与 pdf；PDF 为最终排版 |
| 03_分析代码 | 清洗、聚合、图表、答辩与报告入口，含运行说明、结构字典和测试 |
| 04_数据与协作说明 | 数据来源与字段说明、分工与贡献说明、大模型使用记录、数字复核说明 |
| 05_展示系统 | 离线 HTML 答辩、逐页讲稿与启动说明 |
| 06_复现依据 | 课程任务书、受保护 ADS、清洗稽核、关键数字证据、来源核查与报告插图 |

## 阅读顺序

1. 先看 `02_报告` 中的两份 PDF，了解分析结论与质量结论。
2. 需要核对数字时，查 `06_复现依据/关键数字证据.json` 与 `06_复现依据/ads.json`。
3. 需要运行代码时，从 `03_分析代码/README_课程复现.md` 开始；依赖、数据准备和命令均在其中。
4. 答辩演示直接打开 `05_展示系统/index.html`，无需联网。

## 说明

- 两份正式报告使用 Word 原生标题样式、自动目录和页码，导出 PDF 前已更新目录与域。
- 图表统一使用蓝粉主题、开源字体、16:9 画布和 200 dpi；报告插图为 15.4 厘米宽。
- 数据来源为 OneBST/GI_gacha_dataset 的 DS03；来源声明限定用于学习和交流，详见 `04_数据与协作说明/数据来源与字段说明.md`。
- ADS 以 5 个贡献账号为发布门槛，不足门槛的指标与人数一并隐藏；报告中不出现逐账号指标。
- 大模型使用情况记录在 `04_数据与协作说明/大模型使用记录.md`，并作为附录收入两份报告。
