# 测试说明

本文说明本项目的测试范围与运行方式。

## 范围

测试只覆盖数据流水线（config、geo、dwd、dims、db、quality、pipeline），不覆盖出图与答辩页面。
`test/contract/` 锁定模块对下游的承诺，`test/unit/` 锁定单个函数的行为。

所有测试使用临时 SQLite 空表或合成记录，不读取 `data/`，不连接真实库，也不修改原始库。
因此任何人取得代码后都可以直接运行，不会接触业务明细。

## 运行

在项目根目录执行：

```bash
python -m pytest
python -m pytest test/contract
python -m pytest test/unit -v
```

导入路径由 `pyproject.toml` 的 `[tool.pytest.ini_options] pythonpath = ["src"]` 配置，
测试代码不修改 `sys.path`。

## 修改代码时

- 改动清洗或聚合口径，先补或改对应的契约测试，再改实现。
- 测试期望值应来自规则或已发布聚合，不要为了让测试通过而放宽断言。
- 新增测试仍只使用合成数据；需要真实库对账时，在本地单独执行，不把数据库放进材料包。
