# 测试说明

本文说明本项目的测试范围与运行方式。

## 范围

Python测试覆盖清洗、聚合、答辩构建和开场片制作；页面交互另由JavaScript契约检查。
`test/contract/` 锁定模块对下游的承诺，`test/unit/` 锁定单个函数的行为。

所有测试使用临时 SQLite 空表或合成记录，不读取 `data/`，不连接真实库，也不修改原始库。
因此任何人取得代码后都可以直接运行，不会接触业务明细。

## 运行

在项目根目录执行：

```bash
python -m pytest
python -m pytest test/contract
python -m pytest test/unit -v
```

导入路径由 `pyproject.toml` 的 `[tool.pytest.ini_options] pythonpath = ["src"]` 配置，
测试代码不修改 `sys.path`。

## 修改代码时

- 改动清洗或聚合口径，先补或改对应的契约测试，再改实现。
- 测试期望值应来自规则或已发布聚合，不要为了让测试通过而放宽断言。
- 新增测试仍只使用合成数据；需要真实库对账时，在本地单独执行，不把数据库放进材料包。

## 开场片连续转场检查

当前项目共77项合成数据测试。`test/unit/test_opener.py`另检查白光覆盖率、媒体时间戳、稳定白场和构建目录边界。
`check_flash_clock.cjs`用DOM桩连续模拟60fps，覆盖四种窗口比例和两种时钟路径，检查连续缩放、仅在稳定白场恢复比例、零自动全屏请求；此检查不等同于浏览器实播。
`check_transition.cjs`对实际连续播放逐帧采样，检查缩放和标识转场；发布前仍需人工实播确认视觉效果。
素材与成片不随课程材料提供，运行视频契约检查前需先构建成片。
